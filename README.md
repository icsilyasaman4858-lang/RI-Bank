# بینک تجوری: APK بنانے کا طریقہ

1. github.com پر نیا **Private** repository بنائیں (نام مثلاً `bank-tijori`)۔ اسے Private ہی رکھیں۔
2. اس فولڈر کی تمام فائلیں (`www`, `.github`, `package.json`, `capacitor.config.json`, `.gitignore`) repository میں اپلوڈ کر دیں۔
   ویب پر: Add file > Upload files۔ `.github` فولڈر چھپا ہوتا ہے، اس لیے فولڈر سمیت گھسیٹ کر ڈالیں۔
3. Branch کا نام `main` ہو۔ اپلوڈ ہوتے ہی Actions ٹیب میں "Build APK" خود چل پڑے گا۔ نہ چلے تو Actions > Build APK > Run workflow دبائیں۔
4. 5 سے 10 منٹ بعد کام مکمل ہو جائے گا (ہرا نشان)۔ اس پر کلک کریں، نیچے Artifacts میں `bank-tijori-apk` ملے گا۔ اسے ڈاؤن لوڈ کریں، اس کے اندر `app-debug.apk` ہے۔
5. APK فون میں منتقل کر کے کھولیں۔ اینڈرائیڈ "نامعلوم ذرائع سے انسٹال" کی اجازت مانگے گا، دے دیں۔
6. ایپ کھولیں، پاس کوڈ بنائیں، اور سیٹنگ میں جا کر انکرپٹڈ بیک اپ بنا لیں۔

اہم باتیں:
- یہ ایپ اسکرین شاٹ اور recent apps کی تھمب نیل بند رکھتی ہے تاکہ PIN وغیرہ کہیں محفوظ نہ ہو جائیں۔
- APK کے اندر کا ڈیٹا انسٹال کرنے پر نیا ہوتا ہے۔ پرانی ویب ایپ کا ڈیٹا اس میں خود نہیں آئے گا۔ ویب ایپ کی سیٹنگ سے بیک اپ بنا کر نئی ایپ کی سیٹنگ میں "بحال کریں" سے لے آئیں۔
- ایپ کا نام بدلنا ہو تو `capacitor.config.json` میں `appName` بدل دیں۔
